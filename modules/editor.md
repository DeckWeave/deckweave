# Редактор

Ответственность: отображение runtime snapshots, selection, настройки и запуск отдельной командой. Расположение: `apps/desktop/src`.

Интерфейс: типы в `types.ts`, клиент в `client.ts`, компоненты Svelte. Core — единственный источник активной страницы и назначений. Команды окна сериализуются; pending/error отображаются явно. Изменение поля сохраняется без Apply. UI не запускает действия на выбор и не подменяет Rust runtime browser-local моделью.

Собственный UI en/ru, пользовательские названия сохраняются как введены. [UI](../docs/UI.md), [план](../docs/PLAN.md).
