# Хранение

Ответственность: транзакционное сохранение конфигурации. Расположение: `crates/deckweave-core/src/store.rs`.

Интерфейс: `Store::open`, `load`, `save`; SQLite connection принадлежит одному Core. В памяти публикуется только сохранённая конфигурация. Ошибки открытия/декодирования/commit передаются вызывающему коду. Данные неизвестной версии не сбрасываются.

Runtime pressed/feedback не сохраняются как конфигурация. Импорт старых данных исключён. [ADR](../docs/adr/0002-storage.md), [план](../docs/PLAN.md).
