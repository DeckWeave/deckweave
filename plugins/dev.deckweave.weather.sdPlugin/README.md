# DeckWeave Weather

Необязательный погодный плагин GPL-3.0-or-later. Работает через тот же WebSocket host, что и Elgato actions; погодная логика не добавляется в ядро приложения. Поиск города требует явного выбора результата. IP и текущее местоположение не определяются.

## Настройка

В редакторе найти **DeckWeave Weather**, перенести Current или Forecast на кнопку/область панели, открыть «Настройки плагина», найти город и выбрать результат. Настройки сохраняются сразу. Для прогноза доступны +1/+3/+6/+12/+24 часа, единицы °C/°F. en/ru берутся из языка приложения при открытии инспектора.

Кнопка показывает температуру, ощущения и ближайший закат; Forecast — выбранный горизонт и вероятность осадков. Панель адаптируется к ширине: независимая область 200×128 или полоса 800×128 с тремя горизонтами. Оранжевая точка обозначает устаревший ответ. Нажатие повторяет запрос после сетевой ошибки с ограничением частоты.

## Перенос старой реализации

Из `G:/APPS/DeckWeave/plugins/weather` перенесены принципы валидации текущих данных, null-значений, горизонтов прогноза, локальной timezone и выбора следующего известного заката. Старый process SDK/редактор документов не переносится: адаптер и SVG представление написаны под текущий host. Импорт прежних настроек не предусмотрен по принятому решению проекта.

## Сеть и состояние

Данные [Open-Meteo Forecast API](https://open-meteo.com/en/docs), поиск [Geocoding API](https://open-meteo.com/en/docs/geocoding-api), названия мест GeoNames. Бесплатный endpoint используется для личного некоммерческого применения. Данные передаются только для выбранных координат; автоматического определения IP нет.

Обновление раз в 15 минут; ошибки повторяются не чаще раза в минуту. Кеш разделяется действиями с одинаковыми координатами, ограничен 16 местами и живёт в процессе. Каждое подключённое действие хранит собственные язык, вид и единицы. После перезапуска запрашиваются свежие данные. Таймаут HTTP 8 секунд, ответ не более 256 KiB; редиректы не разрешаются. Скрытые действия не инициируют новые запросы. Старый ответ остаётся помеченным при сетевой ошибке, отсутствующие значения не подменяются нулями.

## Проверки

`npm run test:weather` — deterministic parsing/timezone/forecast/null/polar/stale/HTTP limits/escaping. `npm run check` включает этот набор. Отдельный live запрос для публичного London подтвердил выбор города, текущую температуру, 72 часовых значения и три дня solar data. Работа в native editor и виджета проверяется отдельно от HTTP.
