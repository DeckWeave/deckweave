# Panel Lab

Диагностический native Panel widget DeckWeave. Назначается области панели, поддерживает её размер, pointer phases, неизвестный Y, swipe и несколько связанных крутилок. Drag меняет значение 0–100, вращение меняет его по detents, push/swipe меняет цвет. Операций с ОС и внешними сервисами нет.

`Panel` — расширение DeckWeave, не Elgato controller. Состояние этой демонстрации сбрасывается при `willDisappear`. Исходник входит в приложение под GPL-3.0-or-later.

Раскладка подстраивается под canvas: в широком режиме подпись события находится справа, в отдельном слоте — под значением. SVG использует фактический viewBox области, а не сжимает полноразмерную полосу в маленький слот.
