# Mirabox N4 Pro transport

Встроенный аппаратный адаптер первого среза. Отделён от Tauri, SQLite и действий; не является готовым внешним plugin SDK. На Windows обнаруживает vendor collection `5548:1008/1021`, interface 0, usage `FFA0:1`. Клавиатурная и consumer collections не открываются.

Identity — SHA-256 от VID/PID/serial; при отсутствии serial — от USB path. Во втором случае перенос в другой порт может создать новый instance. Неоднозначный identity отвергается. Для одного устройства должен работать один управляющий процесс: StreamDock и старый DeckWeave перед запуском закрываются. ОС может разрешать нескольким приложениям открыть HID; успешное открытие не доказывает исключительное владение.

`discover/open/read/present/heartbeat` — граница транспорта. Один worker владеет одним HID handle. Полный BAT/chunks/STP отправляется последовательно, без перемешивания с heartbeat. Между изображениями читается ввод. Пакеты DIS, CONNECT и BGCLE меняют текущую сессию/отображение; firmware, LOG и постоянная запись не используются.

112×112 JPEG кнопок и 800×128 JPEG полосы повёрнуты на 180° для устройства. Редактор показывает те же байты, поворачивая их обратно. Ограничение кадра кнопки 10 КиБ, полосы 128 КиБ. Полоса передаётся через volatile BGPIC/chunks/STP. Successful write означает передачу HID, не подтверждение изображения камерой/устройством.

## Карта ввода и границы доказательств

При первой приёмке владелец подтвердил правильные изображения, работу K6–K10 и крайней левой крутилки, но обнаружил, что K1–K5 ошибочно исполняли touch назначения. Причина исправлена: `_IMAGE_KEY_MAP` SDK адресует изображения BAT и не описывает входящие key reports. Аппаратный ввод K1–K10 — raw 1–10; вывод K1–K5 — адреса 11–15, K6–K10 — 6–10. Карты намеренно разделены. Keys state 1 — down, 0/2 — up; остальные состояния сохраняются как Unknown.

В захвате устройства touch down — code 00/state 01 с big-endian X в bytes 11–12. Завершение — code 00/state 00 либо 40–43/state 00 с X в тех же bytes. Значения 40–43 — подсказки четырёх firmware-областей, они не определяют число native widgets. Hit testing использует X, геометрию приложения и исходный contact; orphan/повторный up ничего не исполняет. ARX даёт X/Y движения. Передача Down/Up основана на этих записанных событиях, а не на синтетическом отпускании.

Первый touch adapter обслуживает один контакт в областях полной высоты полосы. Движение более 30 pixels по X/Y или firmware swipe отменяет нажатие; потерянное завершение отменяется через 3 секунды. Hold action и навигация свайпом ещё не реализованы. В повторной приёмке владелец подтвердил визуальный вывод BGPIC, ориентацию, крайние touch области и D1 на полосе. Движение/все жесты отдельно не подтверждены. Текущие T1–T5 и строка D1–D4 — тестовая раскладка, не публичный panel SDK.

Вращение четырёх dials передаётся signed ticks. Нажатия кодов 37/35/33/36 обрабатываются как самостоятельный Click: наблюдаемого release/hold для них не заявляем. Поворот и Click первой крутилки подтверждены владельцем; остальные требуют отдельной аппаратной проверки.

CLI `cargo run -p deckweave-n4 --bin n4-scan --offline` только перечисляет поддерживаемые устройства, не открывает рабочую сессию и не меняет экран.

## Происхождение

- Низкоуровневая структура пакетов/ACK и рендеринг адаптированы из старого DeckWeave, commit `b3098df5df16253031a8703c579fe9ce7e22e38f`, файлы `plugins/device-n4pro/src/{display.rs,report.rs,runtime/native.rs,display/render.rs}`. Лицензия приложения сохранена GPL-3.0-or-later. Старые runtime, apply protocol и данные пользователя не перенесены.
- Адреса вывода изображений сверены с [официальным StreamDock Device SDK](https://github.com/MiraboxSpace/StreamDock-Device-SDK/blob/324d498de6981ee5d9d437bf05818599b3c20781/Python-SDK/src/StreamDock/Devices/StreamDockN4Pro.py), commit `324d498de6981ee5d9d437bf05818599b3c20781`. Адаптер написан в Rust, Python runtime не включён. Входящая карта исправлена по [захвату владельца](../../docs/evidence/2026-11-01/n4-owner-first-input.json), выбранные raw edges включены в `tests/fixtures/owner-1021.json`; старые decoded labels в полном захвате сохранены как свидетельство ошибки, не как ожидаемый результат теста.
- `assets/IBMPlexSans.ttf` перенесён из старого проекта; IBM Plex, SIL Open Font License 1.1, текст лицензии сохранён в [assets/OFL.txt](assets/OFL.txt). Шрифт не изменён.

Lifecycle, очередь желаемых кадров, generation и диагностика находятся в `apps/desktop/src-tauri/src/hardware.rs`. [План](../../docs/PLAN.md), [модуль providers](../../modules/providers.md).
