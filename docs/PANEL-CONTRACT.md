# Контракт сенсорной панели

Панель — самостоятельная поверхность. У страницы может быть свой layout из 0–64 непересекающихся областей с нормализованными координатами. Область содержит обычный action instance; её ID не зависит от номера крутилки. Один fullscreen widget и много независимых widgets используют один механизм. Геометрия Core служит одновременно редактору, renderer и hit testing.

`Page.panel.regions[]`: стабильный UUID, имя, `rect: [x,y,width,height]` в диапазоне 0–1 и явный список связанных `dials`. Один dial принадлежит не более чем одной области текущей страницы. При связывании пустая область получает прежнее действие крутилки; заполненная область переназначает крутилку на своё действие. Скрытое прежнее назначение не восстанавливается после unlink. Глобальные pinned относятся к физическим keys/dials; области принадлежат layout страницы. Независимое действие крутилки отделяется от общей области, сохраняя widget. [Навигация и исправление ограничений](NAVIGATION-AND-DISPLAY-FIX.md).

Контроллеры действий различаются:

- `Keypad`: законченный tap превращается в keyDown/keyUp; отменённое касание не отправляет ни одного события клавиши.
- `Encoder`: rotation/push связанной крутилки и touchTap её области принадлежат одному context. Action Wheel оставляет вложенные действия Keypad. Dial Stack захватывает push для выбора; tap исполняет дополнительную функцию выбранного действия.
- `Panel`: собственное расширение DeckWeave. Плагин получает pointer phases и относительные координаты, может рисовать всю свою область через setImage и связываться с несколькими dials. Это не Elgato Controller и не должно выдаваться за него. Собственные layout templates являются дополнением manifest, а не изменением исходного формата Elgato.

Encoder layout остаётся логическим canvas 200×100. Native widget получает размер области в native pixels. Изображения и declarative feedback компонуются в одну панель; на N4 preview использует тот же итоговый JPEG, что отправлен устройству. Позиции указателя преобразуются через те же raster bounds.

Для N4 подтверждены X down/up; Pointer ACK содержит X/Y. Владелец принял проверку pointer/drag/Y 2026-11-02: [результат](ACCEPTANCE-NEXT.md). Контракт сохраняет optional Y для пакетов и будущих providers без точной координаты. Router может дождаться pointer sample и затем захватить область; без точного Y допускается только однозначная область на всю высоту. Native Panel получает неизвестный Y явно. Elgato touchTap с внутренней координатной логикой требует точных координат; ограничения должны быть видны, а не замаскированы центральной координатой.

Gesture ownership: обычный tap отменяется при движении/свайпе; native pointer widget владеет своим drag и не запускает одновременно системную навигацию. Системный swipe переключает страницы только при разрешении layout и отсутствии захвата native widget. Нет tap после swipe. Изменение layout отменяет начатые контакты и ещё не разрешённые touch gestures.

Исходные требования и границы Elgato SDK: [исследование](research/2026-11-01/ADVANCED-INTERACTIONS.md), [touchTap](https://docs.elgato.com/streamdeck/sdk/references/websocket/plugin/), [feedback layouts](https://docs.elgato.com/streamdeck/sdk/references/layouts/). Этот документ фиксирует правила реализации; физическая работа новой раскладки отмечается отдельно от программных проверок.
