# Следующая физическая приёмка

Рабочий срез: [STATUS](STATUS.md). Нужна проверка только оставшейся аппаратной неопределённости; ранее подтверждённые K1–K10, исходные T1/T5, D1 и ориентация не повторяются.

Release-сборка запущена с отдельным профилем **Acceptance 2026-11-01**. Прежние профили сохранены, рядом с базой создан deckweave.sqlite3.before-acceptance.bak. В приёмочной раскладке нет запуска программ и горячих клавиш. На странице 1 — fullscreen Panel Lab; K1 Switch, K2 Key Logic, K3 Multi Action, K4 папка, K5 OnAirClock, K6 переход к крутилкам. Страница крутилок отображается номером 3: D1 Encoder Clock, D2 Dial Stack, D3 Action Wheel, D4 независимые left/right/push/tap. K1 возвращает к Panel Lab. Эти примеры можно исследовать по желанию; для необходимой физической приёмки достаточно трёх пунктов ниже.

1. Новые жесты: в fullscreen Panel Lab провести пальцем слева направо. Значение должно следовать X; отметьте, если оно меняется только после отпускания. Касания ближе к верхнему и нижнему краю должны давать разные Y (вверху меньше); `Y: unknown` означает отсутствие точной координаты, это тоже полезный результат проверки.
2. D2–D4: по очереди повернуть вправо/влево и нажать. Значение меняется по направлению, push меняет цвет; подпись `dial-2`, `dial-3`, `dial-4` должна соответствовать физической крутилке. Это проверяет оставшуюся физическую карту, а не повторяет D1.
3. USB: отключить и снова подключить N4. Ожидается Offline → Connected, прежний instance/профиль/страница и восстановление изображения; никаких повторных запусков действий и зависших pressed. Визуальную приёмку дисплея нельзя заменить счётчиком OUT.

Свайп внутри native widget принадлежит widget и не должен одновременно переключать страницу. На странице с обычными dial regions разрешён системный swipe между корневыми страницами. Достаточно сообщить конкретные несовпадения этих наблюдений; raw trace сохраняется приложением без настроек плагинов.
