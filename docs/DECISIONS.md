# Принятые продуктовые решения

Актуально: 2026-11-01. Основание — ответы владельца в чате после исследования. Этот файл заменяет открытые варианты из исследовательского пакета там, где они противоречат принятым решениям.

| Область | Принято |
|---|---|
| Стек | Rust + Tauri 2 + Svelte |
| Ресурсы | Численный бюджет владелец не задаёт. Нагрузку измеряем на типовых сценариях и устраняем необоснованный фоновый расход |
| Виртуальный запуск | Отдельная команда «Проверить»; выбор кнопки не запускает её действие |
| Основа UX | Подробно исследовать установленный Stream Deck; повторить его расположение, способы настройки и удобство прежде собственных усложнений |
| Аппаратное расширение | Один provider обслуживает много независимых instances; синхронные группы позднее |
| Навигация | Выбор профиля/страницы в UI сразу отражается на устройстве; состояние устройства и редактора согласовано |
| Smart Profiles | Открытие настроек останавливает автоматическое переключение всех Smart Profiles на всех устройствах. Дополнительный переключатель режима не требуется. После выхода из настроек автоматика возобновляется |
| Первые дополнительные устройства | IO Type 84, прототип `G:\APPS\io_type_84`; Logitech MX4 по названию владельца. Их реализация откладывается |
| Глубина hardware API | Сначала кнопки/колесо и наблюдение. Предусмотреть отдельные настройки всего устройства, затем конкретные capabilities драйверов: RGB, depth, onboard mappings и т. п. |
| Обязательные функции | Multi Action, Delay, Switch, Smart Profiles, Key Logic hold/double press, pinned actions, Dial Stack и Action Wheel |
| Крутилки и сенсорная полоса | Повторить поведение Elgato; собственные упрощения не должны ухудшать взаимодействие. Keys/Dials фильтруют подходящие действия. Dial Stack и Action Wheel включены в первый полноценный выпуск |
| Самостоятельная сенсорная панель | Поддержать собственный плагин панели с виджетами и собственной раскладкой интерактивных элементов. Панель не ограничивается числом крутилок или ролью их индикатора |
| Области и связь с крутилками | Поддержать готовые области с назначениями совместимых плагинов и связь областей с крутилками: например изменение громкости отражается на панели. Самостоятельная панель и совместная работа с крутилками входят в требования |
| Старые данные | Импорт профилей Elgato/StreamDock и миграция данных старого DeckWeave не нужны. Обратная совместимость старых конфигураций не требуется; совместимость Elgato-плагинов сохраняется |
| Отложено | Синхронные группы, расширенные настройки клавиатуры/мыши, Android-клиент |
| Совместимость | Уровень OpenDeck и доступные совместимые версии достаточны; полнота всех мелких возможностей сторонних плагинов не является целью |
| Свои плагины | После базовой совместимости владелец планирует делать собственные плагины под DeckWeave |
| OBS | Можно использовать готовые открытые реализации; отдельный стандартный obs-websocket adapter допустим. Исследованную старую версию плагина не считать описанием всех современных интеграций |
| Лицензии | Сохраняем GPL-3.0-or-later для приложения и MIT OR Apache-2.0 для SDK/шаблонов по прежней схеме |
| Платформы | Windows 11 сначала, далее desktop macOS/Linux |
| Языки | i18n в основе интерфейса; пока en и ru |
| Доступность эталонного оборудования | Elgato-устройства у владельца нет. Не требовать его приобретения или предоставления для начала разработки; непроверенные аппаратные детали явно отмечать |
| Самостоятельность разработки | Владелец разрешил самостоятельно прорабатывать технические решения, собирать архитектуру и писать код. Обращаться за решением только при критической развилке интерфейса или логики взаимодействия, которую нельзя разрешить по уже принятым требованиям |

Открытые настройки удерживают глобальную паузу Smart Profiles. Закрытие одного окна не возобновляет автоматику, пока остаются другие окна настроек. Это конкретизация принятого правила, не дополнительный продуктовый вопрос.

Уточнение владельца от 2026-11-01: раннее исключение Dial Stack отменено. Владелец считал его управлением потоками звука; после объяснения общего назначения подтвердил Dial Stack и Action Wheel для первого полноценного выпуска. Это требование к выпуску, а не к первой технической демонстрации.
