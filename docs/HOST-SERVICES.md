# Общие звуки и постоянные панели

Помодоро добавлен отдельным сохраняемым заданием, без открытия панели.
Несколько аппаратных действий используют один цикл по владельцу и workspace.
API `focus_get`/`focus_control`, capability `focus:1` и события описаны в
[SDK](../../plugin-sdk/HOST-SERVICES.md); [личная раскладка](PERSONAL-WORKSPACE.md)
и [нативный прогон](evidence/2026-11-03/personal-workspace-native-smoke.json).
Старые countdown и overlay записи не меняли тип или смысл.

Срез 2026-11-03: отдельный сервис ядра, Windows-адаптер звука, окна панелей,
управление в **Настройки → Панели**, согласуемый API плагинов и примеры.
[Контракт](designs/host-feedback/design_draft.md),
[native-интеграция](evidence/2026-11-03/host-services-integration.json),
[замер ресурсов](evidence/2026-11-03/host-services-smoke.json).

## Использование

- В настройках можно создать заметку или таймер, изменить текст, угол экрана,
  координаты, размер, цвета, непрозрачность и пропуск кликов. Для потерянной или
  некликабельной панели есть возврат в видимую область. Удаление требует отдельного
  подтверждения. Закрытие сохраняет запись для повторного открытия.
- **Desktop Tools** в библиотеке: Desktop Note, Desktop Timer, Notification Sound.
  Назначение переносом не выполняет действие. Нажатие либо отдельная команда
  проверки открывает сохранённую панель или воспроизводит выбранный звук.
  Повторное открытие не сбрасывает изменения в общих настройках. Изменённые поля
  PI сохраняются сразу и обновляют только соответствующие поля панели; закрытая
  панель не открывается от изменения настроек.
- У CPU/Memory/Uptime плагина **System Monitor** включите «По нажатию открывать
  панель на рабочем столе», затем выполните действие. Один общий замер раз в две
  секунды обслуживает кнопки и панели; фоновая панель продолжает работать на другом
  профиле или странице. Заметкам и native-таймерам процесс плагина не нужен.

Панели независимы от профилей/страниц/папок и подключения устройства. Содержимое,
открытое/закрытое состояние и положение хранятся в отдельной SQLite-базе
`host-services.sqlite3`. Текущие показания CPU в базу не пишутся. При потере
производителя виджет показывает недоступность; старые цифры не выдаются за живые.

Таймер хранит собственный run ID и состояние. Закрытие панели не останавливает
его; пауза/сброс выполняются явно. Новый звук и длительность применяются при
следующем старте; для новой длительности у приостановленного таймера сначала
выполните сброс. При перезапуске будущий срок восстанавливается, уже прошедший
сигнал не воспроизводится задним числом. Отключение/удаление пакета приостанавливает
его native-таймеры. Старый плагин Timers и его световые уведомления не мигрируют
автоматически и не получают новый звук при обновлении.

Три коротких оригинальных PCM-сигнала создаются локально; громкость меняет только
сэмплы сигнала. Воспроизведение в отдельной ограниченной очереди WinMM, без нового
процесса проигрывателя. Статус finished означает успешный результат Windows API,
а не подтверждение слышимости человеком. Пропуск кликов можно отменить из общих
настроек, даже если сама панель перестала принимать мышь.

## Расширение и границы

SDK и шаблон содержат `HOST-SERVICES.md`, promise-методы `ctx.playSound` и
`ctx.panels`, отдельные `plugin.services` и события фонового контекста. Поддержка
объявляется через `info.deckweave.services`, отдельно от совместимости Elgato.
Хост проверяет пакет, контекст, текущую сессию и revision. Закрытый виджет нельзя
открыть обычным обновлением показаний. HTML плагина не исполняется внутри панели.

Сейчас поддерживаются текстовая заметка, текстовый показатель и native-таймер.
Изображения/закрепление скриншотов и произвольные кнопки плагинов ещё не реализованы
(`images:0`, `callbacks:0`). Другим платформам предстоит адаптер звука. Для этого
среза ограничение — восемь открытых и 128 сохранённых панелей. Ограничение отражает
текущий оконный backend, а не обещание низкой нагрузки при любом числе виджетов.

## Проверка и расход ресурсов

`npm run check` включает модель/плагины/UI; SDK — 27 проверок, шаблон — 3,
реестр — 10. Опционально: `cargo build -p deckweave-desktop --locked`, затем
`node scripts/smoke-host-services.mjs`. Native-стенд существует только в debug,
проверяет отдельный каталог внутри `.local`, использует виртуальные устройства
и другой single-instance identifier. Для полного дерева процессов Windows CIM
может потребовать повышенные права. Он не открывает рабочую базу и не пишет HID.

На этой машине (24 логических процессора), debug Rust + production web assets,
один виртуальный редактор: исходно 197 МиБ private memory, +1 панель — 229 МиБ,
+4 — 317 МиБ. Полный замер 0/1/4/8/закрытие и показатели CPU записаны в
[JSON](evidence/2026-11-03/host-services-smoke.json). Это короткие ориентировочные
замеры процесса и его потомков, не release-бюджет и не длительный нагрузочный тест.
Суммарный working set содержит общие страницы и не равен уникальной RAM.

Первоначально первая панель создавала второй browser environment: 362 МиБ
вместо 229 МиБ суммарно. Совместный `web-editor` каталог устранил лишнее дерево;
[предыдущий замер](evidence/2026-11-03/host-services-before-sharing.json) сохранён
для сравнения. При закрытии восьми панелей число процессов вернулось с 16 к 8;
после короткого ожидания оставалось около 221 МиБ, включая кэш браузера.
Стоимость отдельного WebView остаётся заметной: это основание для дальнейшей
оптимизации renderer при расширении типов виджетов.

Native-прогон подтвердил настоящую связь Node SDK → аутентифицированный хост →
CPU-панель, сохранение фонового виджета после смены профиля, завершение закрытого
таймера и успешное воспроизведение нулевого по громкости PCM через Windows.
Дополнительный прогон настоящего Desktop Tools подтвердил обновление текста
закрытой заметки через сохранение настроек без повторного открытия окна.
В рабочей release-сборке визуально проверены список/форма панели и отдельная
заметка. Из тестовой заметки пользователя не создавалась аппаратная привязка.

Осталась короткая проверка на реальном рабочем месте: слышимость и приятность
сигналов; мышь на панели, её перемещение и пропуск кликов; положение на другом
мониторе/DPI. Модель хранения проверяет перезапуск и конфликтующие изменения;
физическую геометрию нескольких мониторов она подтвердить не может.
