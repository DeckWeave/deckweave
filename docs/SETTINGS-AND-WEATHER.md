# Настройки, редактор и погода

Срез от 2026-11-02 продолжает [исправления навигации](NAVIGATION-AND-DISPLAY-FIX.md). До изменений через Windows UI изучены установленный Stream Deck 7.6.0 (23012), главный редактор и Preferences → General/Devices. Опорные решения Elgato: компактный выбор устройства/профиля, отдельный Preferences, спокойная библиотека с раскрываемыми группами, крупное превью и отделённый инспектор.

## Организация интерфейса

Окно `main` теперь — Настройки: Общие, Устройства, Плагины, О приложении. Прежний экран «Ваши устройства» заменён списком с выбранным устройством и его параметрами. Из любого editor настройки открываются шестерёнкой; меню tray открывает то же окно. Повторное открытие использует существующий instance окна. Выпадающий список устройств в editor открывает отдельный editor другого instance.

Общие настройки: en/ru, масштаб превью 75–150%, компактность интерфейса и общий переключатель Smart Profiles. Устройство: имя, обычный профиль при отсутствии совпадения приложения, состояние, поддерживаемые элементы управления и свёрнутая диагностика. Изменения проходят через CAS и SQLite и действуют во всех окнах. Несуществующий default profile и неверный масштаб отклоняются атомарно. Это начало общих настроек, а не заявление о готовности всей Elgato Preferences: автозагрузка, screensaver и brightness пока не добавлены.

Любое открытое окно настройки (`main`, device, PI) приостанавливает Smart Profiles глобально. Закрытие последнего возобновляет автоматический выбор, если он включён. Закрытие окна не завершает runtime; явный Выход доступен в настройках и tray.

У редактора убрана техническая подпись первого среза, сокращена верхняя панель, диагностика N4 перенесена из постоянного footer в настройки устройства. Библиотека сгруппирована по навигации/сценариям/плагинам; Keys/Dials показывают совместимые действия плагинов, Plugins — весь каталог. Тестовые Counter/Toggle свёрнуты. Сохраняются drag-and-drop, раздельные выбор/проверка, размеры панелей и геометрия полосы.

## Погода

[DeckWeave Weather](../plugins/dev.deckweave.weather.sdPlugin/README.md) переносит погодные принципы старой версии на новый plugin host, с отдельным простым PI. Current/Forecast работают на кнопках и native Panel. Выбор города, единицы, горизонт, состояния offline/stale и Open-Meteo не требуют встраивания погодной логики в Core.

[Оригинальный Elgato Weather](ELGATO-WEATHER.md) получил отдельный SHA-проверяемый дескриптор и рабочую копию; установленный пакет не изменяется. По решению владельца запуск выключен: оригинальный backend автоматически определяет IP через сторонние службы. Наша погода этой функции не использует.

## Проверка

Сохранение настроек/отказ CAS/restart, глобальное отключение Smart Profiles и пауза Settings проверены новыми интеграционными тестами Core. Полный check включает Svelte, форматирование, clippy, Rust suites, погодные JS tests и local documentation links. Native UI и release-проверка записываются в [доказательства](evidence/2026-11-02/settings-weather.json).

В итоговой release проверены закрытие и пересоздание окна настроек из editor с правильным выбранным устройством, drag-and-drop Current на кнопку/Forecast на область Panel, поиск и выбор London, реальные изображения, сохранение после полного перезапуска и размеров инспектора. Переход создания Settings — асинхронный IPC, как создание device editor в Windows. Физические назначения Mirabox не менялись; читаемость новой погодной композиции на LCD отдельно не наблюдалась.
