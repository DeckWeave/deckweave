# Fn-действия и аппаратные назначения

Текущий порядок настройки описан в [руководстве по Основному слою и Fn](KEYBOARD-ASSIGNMENTS.md). Ручной выбор F13–F24 больше не является обычным шагом: после предложения замены **«Использовать DeckWeave»** приложение само резервирует сигнал, сохраняет действие и проверяет аппаратную запись.

Fn-действия по-прежнему хранятся в `profile.fn_bindings`, но аппаратное владение находится отдельно, в `Device.keyboard_aliases`. Назначение в клавиатуре общее для профилей; действия меняются по профилю без новой записи в устройство. Удаление действия сохраняет аппаратный резерв. Возврат прежней функции выполняется отдельной подтверждаемой операцией с условным восстановлением точных исходных байтов.

Новый путь использует Raw Input отдельного процесса провайдера с подтверждением устройства. Он не использует глобальную горячую клавишу как запасной источник. Старые сохранённые Fn-ссылки мигрируют без SET и без автоматической активации; для них доступно **«Завершить настройку привязки»**. Одна лишь запись F13 в клавиатуре не доказывает готовность маршрута.

Пока поддерживается одна логическая активация. Сама Fn не является отдельным источником; физические удержание и отпускание, Key Logic и двойное нажатие этого пути ещё не приняты. «Проверить» выполняет действие программно и не проверяет физический ввод. Подробные состояния, ограничения, исходники и проверки приведены в [едином контракте](KEYBOARD-ASSIGNMENTS.md).
