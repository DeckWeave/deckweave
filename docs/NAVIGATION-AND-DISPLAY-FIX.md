# Восстановление изображения и настройка навигации

Дата 2026-11-02. Продолжение [уточнения редактора](EDITOR-REFINEMENT.md) после сообщения владельца: физические дисплеи чёрные, хотя preview и ввод работают.

## Изображение

Изменение JPEG на 4:4:4 и оптимизированные таблицы Huffman было принято по программному декодированию; аппаратного подтверждения не было. Владелец сообщил о чёрных дисплеях. Оба изменения отменены вместе: возвращён прежний baseline JPEG, стандартные таблицы, качество 85/65/45 и 4:2:0. По этому наблюдению нельзя отдельно установить, какой из двух параметров не поддерживается firmware. Сохранены геометрия, полный raster 112×112 и Lanczos3.

Тест проверяет SOF0 и sampling 0x22, транспортный лимит и декодирование. Успешная запись HID и картинка в preview не доказывают, что firmware отобразила JPEG. После запуска исправленной release-сборки владелец подтвердил восстановление картинок на физических кнопках и полосе: «Да, изображения вернулись».

## Крутилка для страниц

В Dials есть действие «Перелистывание страниц». По умолчанию вращение влево выбирает предыдущую обычную страницу, вправо — следующую, с переходом через край списка. Папки не расходуют номера. В свойствах можно выбрать фиксированное направление для отдельного действия.

Чтобы одна крутилка работала на всех страницах и профилях, включить «Закрепить на всех страницах и профилях». Pinned теперь поддерживает физические keys и dials.

При назначении самостоятельного действия крутилке, управлявшей общим native Panel widget или областью с несколькими крутилками, она отделяется от общей связи. Виджет и его назначение сохраняются, оставшиеся крутилки продолжают им управлять. Явное назначение Panel-плагина на связанную крутилку продолжает настраивать общую область.

Ограничение «Only native Panel widgets can be linked to multiple dials» удалено: встроенные и Encoder действия также могут обслуживать общую область. Проверка несовместимости controller с физическим типом элемента сохраняется.

## Папки

Выбрать кнопку папки и нажать «Открыть папку», либо дважды щёлкнуть её на preview. Откроется её раскладка; назначения переносятся из библиотеки на внутренние кнопки обычным способом. Выбор папки для редактирования синхронизирует изображение устройства, не исполняя её вложенные действия. «Назад» возвращает на родительскую страницу.

Настройка «Закрывать после запуска действия» доступна у выбранной папки и внутри неё. По умолчанию выключена. При включении запуск действия возвращает на один уровень вверх. Последовательность продолжает выполняться в фоне; это выход после запуска, а не ожидание завершения внешней программы или ответа плагина. Key Logic закрывает папку после разрешения жеста, не после первого неопределённого нажатия. Пустая кнопка, Cancel и переход в подпапку не вызывают автозакрытие. События плагина сохраняются в очереди до доставки после перехода.

## Проверки

Общий check проходит: 70 Rust-тестов, Svelte без предупреждений/ошибок, format, clippy и web build. Новые проверки используют настоящий SQLite restart, Core input/таймер, shared native Panel, pinned dial, pin/unpin на другой странице, folder navigation, plugin release и delayed sequence.

В установленной release-сборке через Windows UI на отдельном виртуальном устройстве проверены drag-and-drop «Перелистывание страниц» на D1, закрепление, переход вправо/влево между страницами, открытие папки двойным щелчком и кнопкой, перенос счётчика внутрь папки и автозакрытие после «Проверить». При повторном открытии внутренний счётчик показывает 1. Настройки физического устройства этими проверками не изменялись.
