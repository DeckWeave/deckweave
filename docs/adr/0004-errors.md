# ADR-0004: Явные ошибки без пользовательского Apply

Дата: 2026-11-01. Статус: принято в рамках делегированных технических решений.

Варианты: скрытый fallback/reset и best-effort сохранение; типизированная ошибка с прежним рабочим состоянием. Выбран второй вариант. Core возвращает code/message; UI показывает ошибку около операции, не требует grant/draft/review/apply.

Конфликт revision не затирает свежие данные; повреждённая БД не заменяется пустой. Отказ одного external backend не завершает соседние процессы или provider instances. Временный runtime feedback не выдаётся за успешное исполнение внешней команды, если плагин не предоставляет подтверждения.

Последствия: потребуется последовательная обработка pending/error в UI и диагностика причин. Пользователь получает понятный результат настройки; техническая транзакция остаётся внутри host.
