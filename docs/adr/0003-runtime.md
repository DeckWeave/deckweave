# ADR-0003: Один владелец состояния

Дата: 2026-11-01. Статус: принято в рамках делегированных технических решений.

Варианты: собственные состояния и runtime в каждом окне; единый Rust Core. Выбран единый Core. UI selection локален, активная навигация и назначения принадлежат runtime instance. Все command mutations сериализованы и проверяют revision.

Первый срез — короткие синхронные команды под mutex. Асинхронные plugin IO/Delay запрещено исполнять под ним; при их добавлении вводится actor queue и отдельные executors. Press latch адресует исходный action instance после перехода страницы. Конфигурация публикуется после успешной записи.

Последствия: окна не спорят о странице и сохранении. События используются для invalidation, snapshots остаются источником отображения. Сложные scheduler/plugin lifecycle не прячутся в Svelte-компонентах.
