# ADR-0001: Rust, Tauri 2 и Svelte

Дата: 2026-11-01. Статус: принято владельцем.

Контекст: Windows 11 сначала, переносимый runtime, Elgato HTML PI/backend и ограничение расхода ресурсов без произвольного численного бюджета.

Варианты: GPUI плюс отдельный HTML-host; Tauri 2 плюс Svelte. Выбран Tauri 2/Svelte по ответу владельца. Чистая SPA на Vite, без SSR и обязательного web-сервера. Зависимости фиксируются lock-файлами.

Последствия: исходные HTML PI проще размещать, но browser lifecycle и расход всего дерева процессов требуют проверки. Закрытие редактора не означает остановки активного HTML backend. [Исследование](../research/2026-11-01/PERFORMANCE.md).
