# ADR-0006: Самостоятельная поверхность и host-owned action slots

Дата: 2026-11-01. Статус: принято как техническая реализация требований панели; compositor/plugin API ещё не написаны.

## Контекст

Панель должна показывать собственные виджеты и раскладку плагина, размещать совместимые действия в областях и взаимодействовать с крутилками. Фиксировать число областей по количеству dials нельзя. Прямое вложение одного чужого plugin runtime в другой теряет управление contexts и lifecycle.

## Решение

Provider descriptor содержит отдельную surface с bounds, pixel format и подтверждёнными touch capabilities. Panel instance задаёт layout внутри surface: собственные visual/hit regions и action slots. Собственный плагин может отдавать изображение всей области и именованные интерактивные зоны; ему не требуется описывать каждый виджет ограниченным Elgato layout JSON.

Host владеет назначениями action slots, action contexts и их настройками. Панель предлагает стабильные region IDs и geometry; пользователь помещает туда совместимое действие обычным редактором. Плагин панели не создаёт невидимые назначения в чужом плагине и не вызывает его процесс напрямую. Для стандартного layout доступны области по dials; для своего layout их количество и размеры задаёт panel plugin.

Dial association ссылается на action slot/функцию панели независимо от её положения. Feedback action обновляет виджет через binding; внешние изменения состояния идут тем же путём, что изменения от вращения. Временный индикатор — управляемый слой host, который восстанавливает прежнюю панель и её input ownership после скрытия.

Frame и hit map принадлежат одной render revision. Смена раскладки применяется согласованно; поздний кадр старой revision отбрасывается. Геометрия хранится в логических координатах поверхности; один transform применяется к preview, output и touch hit testing. Без подтверждения доставки протоколом host знает только последний отправленный кадр, а не точный момент его физического показа.

Elgato Encoder slot сохраняет logical canvas и touchTap/dial events. Keypad slot на touch создаёт down/up по подтверждённому жесту provider/host; отсутствие настоящего contact lifecycle не выдаётся за поддержку удержания. Native panel plugin может получать более богатый ввод при capabilities устройства. Gesture resolver назначает одного владельца жеста: swipe навигации не дублируется tap вложенного action.

## Последствия для редактора

Пользователь выбирает саму панель для её типа/параметров, область — для конкретного назначения, крутилку — для её действия/связи. Выбор ничего не запускает; «Проверить» остаётся отдельным. Host показывает только действительные возможности выбранного назначения и устройства. Свободное размещение виджетов ограничено поверхностью устройства; бесконечный canvas устройств не нужен.
