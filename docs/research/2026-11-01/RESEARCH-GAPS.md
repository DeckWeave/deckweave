## Приоритетные трассы эталона

| Проверка | Что записать | Текущее свидетельство |
|---|---|---|
| Switch: три запуска A/B/A | Действия, иконка/подпись до и после down/up, текущая/следующая ветвь | Формы просмотрены; чередование подтверждено документацией, runtime не проверен |
| Switch во время Delay, ошибка дочернего шага | Повтор игнорируется/ставится в очередь/запускается снова; момент смены ветви | Не проверено |
| Restart, уход со страницы и возврат | Сохраняется ли выбранная ветвь/состояние | Не проверено |
| Multi Action с двухсостоянийным дочерним действием | Явный userDesiredState и фактический результат повторного запуска | SDK описан; внешний эталон не исполнен |
| Key Logic single/double/hold, затем Switch внутри ветви | Пороги, подавление лишних ветвей, изменение кнопки | Формы просмотрены; runtime не проверен |
| Dial Stack | Порядок выбора, feedback, tap после захвата push стеком, возврат/сохранение | Официальное описание, скриншоты; исполнение не проверено |
| Action Wheel | Различие выбора и запуска; крайние элементы; вложенные/недоступные actions | Официальное описание; исполнение не проверено |
| Полоса: tap/long touch/swipe/press-and-turn | Доставка события, координаты, отсутствие двойного запуска tap+swipe | SDK и UI StreamDock; физические жесты не проверены |
| Press → другая страница → release | Как эталон завершает исходный контекст и очищает held action | Отдельный риск найден в OpenDeck; Elgato не измерен |

Для каждой пробы нужен небольшой обратимый профиль, безопасные markers и журнал входа/feedback. Для Elgato-плагина можно использовать диагностический backend, который только пишет события и меняет состояние/изображение; факт запуска в стороннем host не заменит запуск в официальном. Измерение не требует стартовать запись OBS, менять рабочие назначения или выполнять произвольные системные команды.

## Аппаратные ограничения N4

Нужна отдельная приёмка настоящих press/release крутилки, длинного касания, свайпа и системы координат установленной firmware. Прежний capture ACK ARX и официальный SDK подтверждают координатные пакеты; они не подтверждают полный contact lifecycle. Если firmware выдаёт только click или touch point, нельзя объявлять синтетическое удержание эквивалентом физического. Во время аппаратной сессии один владелец HID: не открывать DeckWeave-транспорт одновременно с рабочим StreamDock.
