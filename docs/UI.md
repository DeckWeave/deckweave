# Интерфейс первого приложения

Основа — [требования](DECISIONS.md) и [обход Elgato](research/2026-11-01/STREAM-DECK-WALKTHROUGH.md). Первый рабочий срез не означает завершённый паритет.

## Основные сценарии

Реестр показывает configured instances, статус и кнопку открытия. Одно нажатие открывает или поднимает окно устройства. Добавление виртуального устройства — отдельная явная команда; оно не выдаётся за подключённый N4.

В окне устройства сверху профиль и название, в центре фиксированная геометрия, справа библиотека, снизу настройки выбранного назначения. Страницы находятся под устройством. Выбрать контрол и действие — два действия; параметры сохраняются после изменения поля без Apply. Выбор не выполняет команду. «Проверить» создаёт down/up в том же runtime; нажатие видно отдельно от выбора и action state.

```text
название устройства / профиль                   Keys | Dials | Plugins
                                               поиск действий
         [физическая геометрия]                 библиотека
         [сенсорная поверхность]
         [крутилки]
         страницы / добавить
--------------------------------------------------------------
выбранный контрол / тип действия / параметры       Проверить
```

## Состояния

| Состояние | Представление |
|---|---|
| Нет устройств | Объяснение и добавление виртуального instance |
| Нет назначения | Номер контрола и подсказка выбрать действие |
| Выбран | Рамка выбора; никаких внешних эффектов |
| Нажат | Отдельная подсветка, снимаемая по up/cancel |
| Feedback | Значение/состояние действия внутри контрола |
| Сохранение | Короткий статус, ошибка остаётся видимой |
| Недоступен backend | Явная ошибка, назначение сохраняется |
| Browser preview | Сообщение, что для Rust runtime нужен desktop; без незаметной подмены локальным fake store |

## Сенсорная поверхность

Может содержать собственную панель с произвольными виджетами либо подготовленные области с совместимыми действиями. Число элементов не ограничивается крутилками. Связь области с dial — часть назначения. До реализации соответствующей фазы редактор не показывает неработающие настройки внешнего panel plugin как готовые. Геометрия поверхности уже отделена от keys/dials; бесконечного canvas устройств нет.

## Язык и клавиатура

Оболочка содержит en/ru; имена пользовательских действий не переводятся автоматически. Стандартные кнопки и поля доступны с Tab/Enter; отдельный запуск не привязывается к обычному выбору. Языки чужих PI определяет пакет. Неподдержанные действия скрыты либо явно обозначены; отсутствие импорта профилей не маскируется неработающей командой.
